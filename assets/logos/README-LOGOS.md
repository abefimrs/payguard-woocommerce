# Replacing Placeholder Logos

The `assets/logos/` folder contains placeholder SVG logos in brand colours.
Replace them with official assets before going live.

## Files to replace

| File | Method | Official source |
|---|---|---|
| `bkash.svg` | bKash | [developer.bkash.com](https://developer.bkash.com) → Brand Assets |
| `nagad.svg` | Nagad | [nagad.com.bd](https://nagad.com.bd) → Media |
| `rocket.svg` | Rocket | [dutchbanglabank.com](https://www.dutchbanglabank.com) |
| `upay.svg` | Upay | [upaybd.com](https://upaybd.com) |
| `card-visa.svg` | Visa | [visa.com](https://www.visa.com) → Brand Center |
| `card-mastercard.svg` | Mastercard | [brand.mastercard.com](https://brand.mastercard.com) |
| `card-amex.svg` | Amex | [americanexpress.com](https://www.americanexpress.com) → Brand Standards |
| `tap.svg` | TAP Wallet | From your PayGuard/TAP account dashboard |

## Format

PNG or SVG both work. Recommended: **120×40px** for MFS/wallet logos, **80×40px** for card logos.
